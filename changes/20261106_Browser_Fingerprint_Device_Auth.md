# Change Document: 20261106_Browser_Fingerprint_Device_Auth

- **Date:** 2026-11-06
- **User Request:** 브라우저 정보등으로 간단한 본인증명을 하면 어때?
- **Proposed Changes:**
  1. 기기/브라우저 기반 무인증 본인 식별 (Device Token / Fingerprint):
     - 브라우저에 고유한 기기 토큰(UUID 또는 Fingerprint + localStorage)을 생성.
     - 투표 등록 시 `creatorToken`을 생성하여 서버에 함께 저장.
     - 본인 기기에서 접속한 경우: 비밀번호 입력란 없이 "자동 인증됨(내 기기)" 배지가 뜨며 터치 한 번으로 즉시 수정 가능.
     - 다른 기기/타인이 해당 이름을 도용하려고 할 경우:
       - 토큰 불일치 시 기기 소유권 보호에 의해 덮어쓰기 방어.
       - 혹시 기기를 바꾼 경우를 대비해 보조 수단으로 "PIN(비밀번호)으로 기기 변경 인증" 옵션을 선택 사항으로 제공.
  2. DB 테이블 `votes` 스키마:
     - `creatorToken TEXT` 컬럼 추가.
  3. 로직 업데이트:
     - 토큰이 일치하면 무조건 본인 인증 성공 (0초 수정 가능).
     - 토큰이 일치하지 않는 다른 브라우저인 경우: PIN 확인을 요구하거나 다른 브라우저에서의 덮어쓰기 차단.
  4. 테스트 작성 (TDD Red -> Green -> Refactor):
     - 동일 기기 토큰으로 비밀번호 없이 즉시 수정 성공 테스트.
     - 다른 기기 토큰으로 접근 시 차단 테스트.
- **Reasoning:**
  - 사용자가 매번 4자리 비밀번호조차 입력할 필요 없이 "내 스마트폰/브라우저"에서 접속하면 알아서 본인인증이 완료되어 사용자 경험(UX)이 극대화됨.
- **Impact Analysis:**
  - 투표 작성자에게 별도 비밀번호 입력을 강제하지 않고 완전 자동화됨.
- **Verification Steps:**
  - Vitest 단위 테스트 통과.
  - Next.js 빌드 통과.
- **Status:** Verified

## Implementation Details
1. **브라우저 고유 기기 토큰 (Device Token) 자동 발급 & 연동:**
   - 브라우저 접속 시 고유 토큰(`wwm_device_token`)이 자동 발급되어 저장됩니다.
   - 첫 투표 시 이 토큰이 서버(`votes.deviceToken`)에 함께 기록됩니다.
2. **원터치 무암호 수정 UX:**
   - 최초 작성한 동일 브라우저/스마트폰으로 재방문 시 "내 기기 인증됨" 뱃지가 뜨며, 비밀번호 입력 없이 날짜만 탭하고 즉시 수정 완료됩니다.
3. **타인 도용 방지 & 기기 변경 대응 (Hybrid):**
   - 다른 기기/타인 브라우저가 해당 이름을 가로채서 수정하려고 하면 즉시 차단됩니다.
   - 혹시 스마트폰을 바꾸거나 PC로 수정하고 싶을 때를 위해 보조 PIN(선택 입력)도 함께 지원됩니다.
4. **검증 완료:**
   - Vitest 단위 테스트 및 Next.js 빌드 통과.
