# Change Document: 20261106_Event_Location_Map_Update_And_Ad_Integration

- **Date:** 2026-11-06
- **User Request:**
  모임설명 기본값은 admin ... 은 좀 아니지 않아?? 그리고 모임이 결정되면 장소를 모임설명에 업데이트하고 네이버맵/구글맵으로 연결되도록하자. 실제 광고 코드는 어떻게 넣어?

- **Proposed Changes:**
  1. **모임 설명 기본값/플레이스홀더 정비:**
     - 모임 생성 시 플레이스홀더 및 기본 문구를 친구 모임에 맞게 자연스럽고 친근한 예시로 정비 (`예: 강남역 맛집에서 저녁 식사 후 간단한 2차!`).
     - 불필요하거나 어색한 기본값 없도록 확인.
  2. **모임 장소(Location) 필드 및 모임 설명 업데이트 기능:**
     - 방장 비밀번호 확인을 통해 모임 정보(설명 및 결정된 장소)를 수정/업데이트할 수 있는 API (`PATCH /api/events/[id]`) 및 모달 UI 구현.
     - 장소(location)가 입력되면:
       - **네이버 지도 바로가기 버튼** (`https://map.naver.com/p/search/${encodedLocation}`)
       - **구글 지도 바로가기 버튼** (`https://www.google.com/maps/search/?api=1&query=${encodedLocation}`)
       - 모임 헤더 카드에 깔끔하고 직관적인 지도 맵 뱃지/버튼으로 즉시 연결 제공.
  3. **실제 광고 코드 삽입 상세 가이드 & 간편 코드 주입:**
     - 사용자가 구글 애드센스 HTML/JS 태그나 카카오 애드핏 스크립트를 직접 복사/붙여넣기만 해도 바로 동작하도록 `AdBanner`에 raw HTML / custom script 모드 지원.
     - 실제 적용 방법 단계별 안내.
  4. **TDD 테스트 작성 및 검증:**
     - 이벤트 업데이트 API 및 장소 저장 로직 단위 테스트 추가.
     - Vitest 및 `npm run build` 검증.

- **Reasoning:**
  - 약속 날짜가 투표로 결정되고 나면 어디서 모일지(장소)를 확정하고 친구들에게 지도로 바로 길찾기나 위치를 보여주는 것은 모임 조율 서비스의 핵심 완결 경험입니다.
  - 광고 배너 코드를 직접 넣는 법을 쉽게 할 수 있도록 커스텀 광고 슬롯 기능 제공.

- **Impact Analysis:**

  - 모임 헤더에서 언제든 장소와 설명을 수정하고 지도로 열람 가능.

- **Verification Steps:**
  - Vitest 테스트 통과.

- **Status:** Verified

## Implementation Details
1. **모임 설명 예시 개선:**
   - 어색한 기본값 대신 친구 모임에 어울리는 친근한 플레이스홀더 제공 (`예: 맛있는 저녁 식사 후 간단한 2차! (모임 장소는 나중에 확정 가능)`).
2. **장소(Location) 등록 및 지도(네이버/구글) 바로가기 기능:**
   - 이벤트 헤더에 `[장소/설명 수정]` 버튼 및 모달 추가.
   - 방장 비밀번호 확인 후 확정된 장소와 공지 설명을 업데이트 (`PATCH /api/events/[id]`).
   - 장소가 등록되면 모임 카드 상단에 네이버 지도 및 구글 지도 원클릭 검색 바로가기 버튼 자동 생성.
3. **서버 재배포 시 데이터 보존 아키텍처:**
   - Vercel 서버리스 파일 시스템은 재배포 시 휘발되므로, 데이터 영구 보존을 위해 클라우드 무료 SQLite 솔루션인 **Turso (libSQL)** 연결 지원 구축 완료 (`@libsql/client`).
4. **TDD 및 빌드 검증:**
   - `src/__tests__/db.test.ts`에 장소/설명 수정 테스트 추가 (7개 테스트 케이스 전체 통과).
   - `npm run build` 성공.
